# 上线与运营（OPS）

站点已通过 EdgeOne 部署为公开页面：

**https://mcp.edgeone.site/share/Sc7rhlJ2Qu-Ef32mwdFMK**

页面本身只有 11 KB，JS/CSS 从 jsDelivr 拉取仓库里的原文件——所以**改仓库即改线上**（jsDelivr 缓存约 12 小时，急更就重新部署一次）。

## 1. 三条上线路径，按稳定性排序

| 路径 | 地址 | 什么时候用 |
|---|---|---|
| EdgeOne Pages | 上面那条 share 链接 | 现在就能发给人看，无需你的账号操作 |
| GitHub Pages | `https://fnhiq23.github.io/agi-engine-v2/`（需 Settings → Pages → Deploy from a branch → `main` / `(root)` 点一下） | 想要长期自有地址 |
| 单文件 `dist/index.html` | 本地文件 | 发给不想点链接的人、或作为 $19 商品附件 |

三条路径跑的是同一份代码，不存在"线上和本地不一致"。

## 2. 上线自检（每次部署后 2 分钟）

1. 无痕窗口打开链接 → 落地页出现、点「开始使用（免费）」能进主界面。
2. 「记忆」写 3 条 → 「生成上下文包」有输出 → 免费版导出按钮是灰的。
3. 「Pro」填演示码（`demo/license-demo.txt`）→ 徐章变 Pro → 回「记忆」导出变可用。
4. 手机上也开一次：确认不是只有桌面能用。

任何一步失败，先看浏览器控制台的第一条红字——90% 是 jsDelivr 分支缓存或 CSP。

## 3. 运营第一周（每天只做一件事）

| 天 | 动作 | 产出 |
|---|---|---|
| D1 | 把链接发给 5 个同时用 2 个以上模型的人，问一句"哪一步让你想关掉" | 5 条真实阻力 |
| D2 | 按阻力改**一处**（只改一处） | 一个可验证的改动 |
| D3 | V2EX「分享创造」发帖（文案见 `docs/LAUNCH.md §5`） | 首个公开流量 |
| D4 | 回帖 + 记录访问/编译/导出三个数 | 第一张数据表 |
| D5 | 小红书或即刻发同一素材（换语气不换事实） | 第二个渠道对比 |
| D6 | 给 D1 里最积极的那个人做一份免费上下文包 | 第一个案例 |
| D7 | 写周报（模板见 §5），决定下周只改哪个变量 | 下周的唯一目标 |

**纪律**：一周只发两个平台，只改一个变量。同时改三件事，你永远不知道什么起了作用。

## 4. 数据口径（只记四个数）

| 指标 | 从哪看 | 判断 |
|---|---|---|
| 访问 | EdgeOne / Pages 的访问统计，或自己数发出去的链接点击 | < 50 说明没人点，是文案问题 |
| 编译（`pack_compiled`） | 用户本机 localStorage `agi_v2_events`（让对方截图给你） | 访问的 20% 以下说明第一步太难 |
| 导出尝试 | 免费版点导出被拦的次数（同上） | 有尝试但没买 = 价格或信任问题 |
| 付款 | Gumroad 后台 | 唯一真指标 |

**不要**用"点赞/收藏"当指标。它们不等于意图。

## 5. 周报模板（每周日 15 分钟）

```
第 N 周（日期）
访问：__  编译：__  导出尝试：__  付款：__  收入：$__
本周唯一改动：______  结果：变好 / 没变 / 变差（用一句话说明证据）
最扎心的一条反馈：「______」
下周只改：______（必须是可验证的一件事）
```

## 6. 客服话术（三句解决 80% 的问题）

- **"这和我自己写 system prompt 有什么区别？"**
  → "是同一件事，区别是它确定、有 token 预算、可每周 diff、能加密带走。手写做不到这四点。"
- **"为什么不能云同步？"**
  → "同步要服务器，服务器要钱，收费就得变订阅。我宁可让你用自己的网盘传加密文件。"
- **"授权码为什么不能退订/吊销？"**
  → "因为是离线校验，不连服务器。所以退款按 14 天无理由，你退了删文件即可。"

## 7. 什么时候停（诚实版）

- 连续 7 天，访问 > 300 且编译 < 10：产品第一步就不成立，回炉重做引导。
- 连续 14 天，编译 > 50 且付款 = 0：定价或信任问题，先做一单免费案例再谈价。
- 30 天总收入 < $30：方向重估，不追加投入。

## 8. 下一步的技术债（按优先级）

1. `demo/` 演示私钥必须删（发第一单前）——现在任何人都能自己签票。
2. Gumroad 付款 → 手动发码（`tools/license.mjs issue`），一天 20 单以内不需要 webhook。
3. 超过 20 单再考虑自动发码（Worker + 邮件），不要提前上服务器。
4. SEO 长尾页（`ChatGPT 记忆导出`、`you.md 模板`）等有第一笔收入再写。
