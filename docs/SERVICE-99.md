# $99 代做上下文包：一单到底的作业手册

> 适用：拿到第一个付费客户之后。目标不是这 $99，而是**48 小时内产出第一条可公开的案例**。
> 纪律：不承诺"AI 会替你想"，只承诺"把你已经说过的话整理成一份能用的文件"。

## 1. 接单（10 分钟）

客户只需要回答 4 个问题（做成表单，别在聊天里一问一答）：

1. 你最常让 AI 做哪三件事？（写东西 / 做决策 / 学东西 / 写代码 / 翻译 / 其他）
2. 你反复要向 AI 解释的 3 件事是什么？（身份、行业、风格禁忌）
3. 你现在用哪几个模型？换模型时最烦的是哪一步？
4. 你愿意把哪些历史对话/笔记给我看？（二选一：自己粘贴 / 导出文件）

**付款前必须说清三句**：
- 交付物是一份 Markdown（`you.md`）+ 一份加密备份 + 一页使用说明，不含任何账号或订阅。
- 我处理你的素材只用本机工具，不上传第三方；交付后 7 天内删除原始素材。
- 14 天无理由退款，退款不需要理由。

## 2. 收素材（客户 20 分钟，你 5 分钟检查）

最小可用输入：**20 条**。低于 12 条时先跟客户说"信息量不够，包会很薄"，请他补。

合格素材长这样：
- 事实类："我在南宁，做 SaaS 产品，团队 6 人"
- 偏好类："写东西要短句，不要'赋能/闭环'这类词"
- 目标类："Q4 要把试用转化率从 8% 提到 15%"
- 反例类："别给我写 5 段式方案，我要三条结论"

不合格（要退回）："帮我写个营销文案"这种**任务指令**，它不是关于客户的信息。

## 3. 编译（15 分钟）

```bash
# 本机跑，不上传
node -e "import('./js/compiler.js').then(m=>console.log(m.compileContext({memories: JSON.parse(require('fs').readFileSync('in.json','utf8')), budgetTokens: 1500}).markdown))"
```

人工校三件事（这一步是 $99 的价值所在，机器做不了）：
1. **删模型幻觉**：编译器不会编事实，但客户素材里常有自我美化，标出来让他确认。
2. **合并同义**：三条"不喜欢长文"合成一条更狠的表述。
3. **补一条客户没想到的**：从他三件事的重复模式里提一条（例如"你每次都要说明受众是谁——把它写成默认规则"）。

## 4. 交付（一封邮件，三个附件）

**中文模板**

```
主题：你的上下文包（you.md + 加密备份）

附件：you.md / you-backup.agi / 使用说明.md

怎么用：把 you.md 全文粘到任何模型对话的第一条，然后正常提问。
换模型时只粘这一份，不用重新自我介绍。

这版我做了三处人工调整：
1) 把"不喜欢长文"合并成一条硬规则；
2) 删掉了两条与事实不符的自述（已标黄）；
3) 加了一条你没提但反复出现的默认：先说受众再说结论。

备份口令：<你设的口令，另发一条消息给，别写在同一封邮件>
14 天内不满意直接回这封邮件退款。
```

**English template**

```
Subject: Your context pack (you.md + encrypted backup)

Attached: you.md / you-backup.agi / how-to.md

Usage: paste the whole you.md as the first message in any chat, then ask normally.
Switch models without re-introducing yourself.

Three human edits I made:
1) merged three "no long text" notes into one hard rule;
2) removed two self-descriptions that didn't match your material (highlighted);
3) added one recurring default you didn't mention: audience first, conclusion second.

Passphrase sent separately. 14-day refund, no questions.
```

## 5. 收尾（决定这单值不值）

交付后 48 小时问一句：**"粘进去之后，有哪一句它理解错了？"**

- 有回答 → 改一版，这就是你的第一个真实案例。
- 没回答 → 说明包没用上，退款或降级为免费，别硬收钱。

把这三样记进 `docs/CASES.md`：客户行业、原话痛点、改前改后各一句（脱敏）。

## 6. 单位经济（一单的真实成本）

| 项 | 时间 | 成本 |
|---|---|---|
| 接单沟通 | 20 min | 0 |
| 收素材 + 检查 | 30 min | 0 |
| 编译 + 人工校 | 45 min | 0（本机跑） |
| 写交付邮件 | 15 min | 0 |
| 备份口令沟通 | 5 min | 0 |
| **合计** | **≈2 小时** | **$0 现金** |

也就是说：$99 的单，毛利≈100%，瓶颈只有"你愿不愿意花 2 小时"。这就是为什么先卖服务——它不需要服务器、不需要公司、不需要投放预算。

## 7. 三条红线

1. 不接"帮我搞定 AI 自动赚钱"这类需求——无法交付。
2. 不把客户素材存进任何云端（含自己的网盘），交付 7 天内删除。
3. 不在未经同意的情况下把客户案例写进宣传（只写脱敏后的行业 + 场景）。
