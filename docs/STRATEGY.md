# 策略：一个没钱但有技术的创始人，怎么让这个东西赚到钱

> 这不是愿景文档，是一份执行约束。凡是写在这里的判断，都要能被数字或一次实验推翻。

## 0. 一句话

**不卖"AI"，卖"记忆资产"。** 产品免费、开源、零服务器；唯一收费的是"把记忆带走"的能力：完整上下文包 + 加密备份 + 不限条数，一次性买断 $19。先靠一次公开发布拿到前 100 个付费用户，再用 $99 的"代做上下文包"服务换现金流。

## 1. 第一性原理：拆到不能再拆

把"个人 AI 工具"拆到原子，只剩两个变量：

```
用户获得的价值 = 模型能力（你没有的） × 你的上下文（模型没有的）
```

- 第一项是别人的资产：OpenAI、Anthropic、本地 Llama。我们一分钱也赚不到，硬卖就是转售 API，毛利为负、合规风险极高。**v1 的"AGI"承诺就是在这个变量上撑谎。**
- 第二项是唯一属于用户、也只能由用户自己积累的东西：他说过的话、偏好、事实、计划。**它现在散在几十个对话窗口里，每次换模型就归零。**

所以这个产品唯一站得住的定位是：**上下文资产的积累器 + 编译器 + 保险箱**。聊天只是采集手段，不是卖点。

推论（每条都直接决定代码和价格）：

1. 聊天框是商品，永远不该收费。ChatGPT 免费版、Cherry Studio、LM Studio、Jan 都比我们成熟。收费点必须在"带走"和"不限量"上。
2. 记忆的价值随条数超线性增长（10 条是玩具，200 条是资产），所以免费额度要小到"够体验、不够依赖"，付费墙放在**导出**而不是**保存**——保存是习惯，导出是资产。
3. 资产必须能脱离我们存在：明文 Markdown、可 diff、加密文件能丢进任何网盘。任何"必须登录我们的服务器才能用"的设计都会杀死这个定位。
4. 因此**不能有月费**：本地工具没有持续成本，收月费等于向用户收"我们不存在的那台服务器"的钱，转化率会塔。
5. 因此**授权必须离线**：一张私钥签名的票，公钥在代码里，激活零成本零延迟。不做数据库、不做 Worker、不做账号体系。

## 2. 我们卖什么、不卖什么

| 卖 | 不卖 |
|---|---|
| 完整上下文包（1500 tokens，可复制可下载） | 模型额度 / token 转售 |
| 加密备份（AES-256-GCM，口令在用户手里） | 云同步（要服务器，也违背定位） |
| 不限记忆与对话条数 | 排行榜、社交、邀请奖励 |
| 离线授权码（可换设备重激活） | 订阅制、"月付会员" |
| $99 代做上下文包（服务） | 任何"AGI/去中心化/链上"叙事 |

**不做什么的清单比做什么更能保命**：v1 死于五个空承诺（假 Pro、假支付、假数据、假邀请、假加密）。v2 的规则是：**代码里没有的能力，界面上一句都不许提。**

## 3. 产品结构（已落地）

```
index.html            单入口，CSP，无内联脚本
js/core.js            纯函数（额度、等级、授权状态、转义）—— 有单测
js/compiler.js        记忆+对话 → you.md（去重、分类、token 预算、确定性输出）
js/vault.js           PBKDF2 + AES-GCM 加密备份
js/license.js         ECDSA P-256 授权码校验（离线）
js/entitlement.js     授权落盘 / 可选在线兜底
js/toolkit.js         资产工具箱（编译 / 导出 / 恢复）—— 免费只给预览
js/app.js             应用壳（聊天、记忆、成就、Pro、设置）
tools/license.mjs     发码 CLI（keygen / issue / verify），私钥永不进仓库
```

免费 → 付费的路径只有一条，且每一步都真实存在：

```
写 3 条记忆（30 秒） → 编译看到"它真的懂我"（免费预览 240 tokens）
→ 想拿走完整版/想备份 → $19 买断 → 输入授权码 → 立刻解锁
```

## 4. 为什么砍掉 $15/月

月付的前提是"我们每月都在为你付出成本"。事实是：0 固定成本、0 边际成本、0 运维。用户一旦发现"付费只是解除一个 localStorage 里的计数器"，价格就会被判定为敲诈，退款和差评随之而来。

买断的三条硬理由：

1. **心理账户**：$19 是"买一个文件/一份资产"，$15/月是"再订一个服务"。前者的决策成本低一个数量级。
2. **无履约压力**：买断不承诺持续更新，只承诺"你现在拿到的能一直用"。这和没团队、没服务器的现实一致。
3. **可验证**：一次性收款 + 一张签名票，整个交易闭环在 3 分钟内结束，不产生任何后续账单、dunning、退订挽留。

价格锚点：$19（首发 100 份）/ $39（标准）。两个价位用两个 checkout 链接做 A/B，跑 200 次访问再定。

## 5. 单位经济（把钱算清楚）

固定成本：域名 ¥0（用 GitHub Pages）、托管 ¥0、授权校验 ¥0、邮件 ¥0（人工发）。
边际成本：0（数字交付）。
唯一真实成本：**你的时间**，以及收款平台抽成（Lemon Squeezy / Paddle 约 5% + $0.5，Gumroad 10%，PayPal 个人约 4.4%+$0.3）。

一次发布的收入模型（不要用"目标 $10,000"骗自己，用区间）：

| 场景 | 有效访问 | 付费转化 | 客单价 | 收入 |
|---|---|---|---|---|
| 冷启动（只有朋友看） | 80 | 1% | $19 | $15 |
| 一个小社区贴有效果 | 600 | 1.5% | $19 | $171 |
| HN / PH 上首页 | 4,000 | 2% | $19 | $1,520 |
| 同上 + 两周长尾 | 8,000 | 2% | $19 | $3,040 |

结论：**单次爆量的期望值是几百到三千美元，不是月入十万。** 想要持续收入，靠的是把每次发布的长尾（SEO、GitHub、被引用）叠起来，以及服务化收入的现金流。

第一个月的现实目标：**$100–$500 产品收入 + $297 服务收入（3 单）**。达不到就按 §10 的杀死条件处理，不要加功能。

## 6. 渠道：只做零成本、可复利、有意图的

排序依据：`可复制性 × 用户意图强度 × 是否留下可被搜索的资产`。

| 优先级 | 渠道 | 动作 | 预期 | 复利 |
|---|---|---|---|---|
| 1 | GitHub + Show HN | 英文 README 首屏 + 一段 30 秒 GIF（记忆→you.md） | 首日 200–4,000 访问 | 仓库本身就是长期落地页 |
| 2 | Reddit r/LocalLLaMA、r/ChatGPTPro | 只发"我做了个把记忆变成 you.md 的工具"，附真实输出 | 50–400 访问/贴 | 帖子被搜索到 |
| 3 | V2EX（分享创造）/ 即刻 / 少数派 Matrix | 中文，讲"为什么我砍掉了月付" | 100–800 访问 | 中文 SEO |
| 4 | 小红书 / 视频号 | 30 秒竖屏：输入 5 条记忆 → 生成 you.md → 粘进 ChatGPT 前后对比 | 长尾，女性/职场人群 | 平台内搜索 |
| 5 | SEO 长尾 | 20 个页面：`ChatGPT 记忆导出`、`本地 AI 记忆`、`you.md 模板`、`AI 上下文 迁移` | 3–6 个月起量 | 最强复利 |
| 6 | 一对一 DM | 在 AI 群里找"同时用 3 个模型"的人，发免费包 + 请他指出哪里没用 | 3 单服务/30 次触达 | 口碑与访谈素材 |

不做的：付费广告（没钱且转化未验证）、KOL 投放、互推联盟、任何"裂变奖励"（v1 已证明是空承诺）。

**发布物料必须包含一个可验证的产物**：一份真实的 `docs/EXAMPLE-CONTEXT.md`。人对"我的记忆长什么样"没有想象力，对一份样例有。

## 8. 现在就要现金流：$99 代做服务

产品需要信任才成交，服务不需要。二者共用同一套能力（compiler + vault），边际成本≈0，交付由我（AI）完成：

**「AI 记忆资产代做」$99 / 次**
1. 客户给 20–50 条素材（聊天导出、笔记、简历、项目文档），脱敏后发我。
2. 48 小时内交付：`you.md`（可粘任何模型）+ 加密 `.agi.json` 备份 + 一页"怎么用"说明。
3. 附赠 30 天内一次免费更新。
4. 交付物本身就是产品 demo，成交客户会变成口碑与案例。

为什么成立：目标客户是"同时用 ChatGPT/Claude/国产模型、被重复自我介绍烦到"的人。他们缺的不是工具，是**把素材整理成资产的那两小时**。这两小时我们卖 $99，合理。

## 9. 收款与发码 SOP（3 分钟一单，零基础设施）

选一个，别纠结：

- **Gumroad**：个人可开，10% 抽成，支持中国收款（PayPal），链接即商品页。最省事。
- **Lemon Squeezy**：5%+$0.5，MoR 代缴税，体验更专业，但审核略严。
- **PayPal 个人收款 + 手动交付**：0 门槛，但无商品页、无自动交付，只适合前 3 单。

每单流程：

```bash
# 1) 看到订单（Gumroad 后台 / 邮件通知），复制订单号
# 2) 本地签发（私钥只在你电脑上）
node tools/license.mjs issue --plan lifetime --exp 2099-01-01 --order GR-1024 --email buyer@example.com
# 3) 把打印出来的 AGIP1.xxx.yyy 连同"激活三步"发回买家
# 4) 在表格里记一行：订单号 / 邮箱 / 发码时间 / 金额
```

规则：
- **先 keygen 再卖第一单**：`node tools/license.mjs keygen`，把公钥贴进 `js/license-pubkey.js`，删掉 `demo/`。仓库里的演示密钥任何人都能拿去签票，留着就是漏洞。
- 私钥丢了 = 所有客户无法重装激活。备份到两台设备 + 一个离线介质。
- 退款：14 天内无理由，退钱不吊销（离线模式无法吊销）。滥用（一码多卖）靠人工识别，超 3 台设备拒绕支持。
- 上线后第一件事：把 `TERMS.md` 里的退款条款和实际流程对齐，别写做不到的。

## 10. 风险与杀死条件（写给未来的自己）

真实风险，按杀伤力排序：

1. **没人需要"记忆资产"**。杀死条件：累计 1,000 次有效访问 < 5 单（<0.5%）→ 说明定位错了，不是页面丑。下一步只允许改定位（换成"给自媒体/律师的素材库"或纯服务），禁止继续堆功能。
2. **服务也卖不动**。杀死条件：30 次有针对性触达 < 3 个咨询 → 渠道错，不是产品错。换渠道，不降价。
3. **免费用户把付费墙当敲诈**。信号：公开评论区出现"就这还要钱"。应对：把免费额度提高（记忆 10→30），付费点更集中在"导出/备份"，并公开成本结构（本文档就是）。
4. **密钥泄露**（演示私钥被利用签票）。应对：发第一单前必须替换公钥；泄露后 keygen 重发全部老客户，成本可接受（<100 单）。
5. **合规**：不碰加密货币、不承诺收益、不代收模型额度、不存用户内容 → 风险面已经压到"卖软件"。仍需：隐私政策与实际一致（已做）、退款条款可执行（已做）、税务按所在地自行申报。

**三个月后如果：产品收入 < $200 且服务 < 3 单，就停止投入这个项目，把 compiler + vault 作为开源库发布，换下一个假设。** 这不是失败，是省下第二个月的时间。

## 11. 分工：我做什么，你必须做什么

我能做（且已经在做）：全部代码、测试、站点、文案、样例、SOP、SEO 页面、发布稿、客服话术、代做交付。

只有你能做（涉及你的身份与钱）：
1. 注册收款账号（Gumroad / Lemon Squeezy / PayPal），填收款信息 —— 我不能代持你的钱。
2. 在 GitHub 网页点一次 Pages（Settings → Pages → Deploy from a branch → main / root）—— 仓库 token 没有建站权限。
3. 跑一次 `keygen` 并保管私钥 —— 私钥不能经过我，也不该进仓库。
4. 决定是否接受"买断 $19"这个定价口径 —— 这是商业判断，不是技术判断。
5. 发布时用你的账号发帖 —— 平台要真人身份，机器人发帖会被封。
