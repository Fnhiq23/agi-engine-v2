## 怎么读这份东西

- **关于我**：事实类，模型不需要再问你"你是谁"。
- **偏好与习惯**：写作风格、饮食、工作方式——最能减少来回返工的部分。
- **目标与计划**：正在推进的事，让建议落在你的现实里。
- **最近在关注**：从你自己的提问里统计出的高频主题（只统计你说的话，不统计模型的措辞）。

它有几个刻意的性质：

1. **明文**：任何编辑器都能改、能 diff、能进 Git。
2. **确定性**：同样的输入永远得到同样的输出，所以你能看出"我这周变了什么"。
3. **有预算**：默认 1500 tokens，超了就截断并标记，不会悄悄塞满半个上下文窗口。
4. **不联网**：编译全程在本机完成，没有模型调用，也不花钱。
